# LzVM
A lightweight expression evaluation engine.

This bytecode engine executes expressions that produce a double output, with ability to perform basic operations and run in a WASM environment through interpretation system.

## Primary use case
Fast MoLang parsing and execution.

LzVM may operate in two modes:
- JVM bytecode - Emits a java class that can be then loaded into the runtime: **FASTEST** but requires to be executed within JVM itself.
- Interpretation mode - Runs the program using a for loop: **SLOWER** but can run in embedded environments such as WASM by not requiring any JVM trickery.

Can be extended with other parsers that produce LzVM bytecode.

We only ship "MoLang" module out-of-box.

## Adding to project

### Gradle

`gradle.properties`:
```properties
lzvmVersion=1.0.0
```

`build.gradle`:
```groovy
repositories {
    maven {
        url = "https://maven.zeith.org"
    }
}

dependencies {
    implementation "dev.zeith.lzvm:LzVM:$lzvmVersion"
    
    // Optional. Adds support for MoLang expressions.
    implementation "dev.zeith.lzvm:MoLang:$lzvmVersion"
}
```

### Usage Guide

1. Obtaining LzProgramBody - intermediary step
   - Can be done using `MoLangCompiler.parseAndCompile`, or generated by yourself.
2. Creating LzFactory - store these factories for instancing later on
   - Use `JzRuntimeProvider.expression` (implemented by `LzJvmCompiler` and `LzVM`)
3. Prepare your `LzVariableStore` with variables and calls populated. One per entity is usually enough.
   - There is a default implementation, `SimpleLzVariableStore` that can be used for making your own store.
   - Additionally, if you don't want to update read-only variables, use `ReadonlyLzVarOp` as a lambda to reference values from your own instances directly.
4. Instance your LzExpression - these may be instanced per context, which is `LzVariableStore`, which contains all relative variables and calls.
   - Call `LzFactory.instantiate(LzVariableStore)`
5. Update your variable values in `LzVariableStore` and call `LzExpression.get()` afterwards.

### Code example: (With MoLang)

```java
import dev.zeith.lzvm.jvm.*;
import dev.zeith.lzvm.molang.compiler.MoLangCompiler;
import dev.zeith.lzvm.program.LzProgramBody;
import dev.zeith.lzvm.vm.SimpleLzVariableStore;

void main(String[] args)
{
	final MoLangCompiler molang = new MoLangCompiler();
	final LzJvmCompiler jvm = new LzJvmCompiler();
	
	// Step 1
	LzProgramBody body = molang.parseAndCompile("math.sin(q.anim_time * 90) * 10");
	
	// Step 2
	LzFactory fac = jvm.expression(body);
	
	long start = System.currentTimeMillis();
	
	// Step 3
	SimpleLzVariableStore vars = new SimpleLzVariableStore();
	vars.registerReadVar("query.anim_time", () -> (System.currentTimeMillis() - start) % 100000L / 1000D);
	
	// Step 4
	LzExpression expr = fac.instantiate(vars);
	
	// Step 5
	for(int i = 0; i < 100; i++)
	{
		System.out.println(expr.get());
		try {Thread.sleep(50L);} catch(InterruptedException ignored) {}
	}
}
```
